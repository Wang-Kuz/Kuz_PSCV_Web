# 连续滚动与视觉验收 · 2026-11-11

## 本轮缺陷与修复
1. 价值观卡片同时受 GSAP 和 CSS 渐入控制；GSAP 把初始 opacity=0 记录为终态。移除旧的重复文字/卡片动画，使用单一原生渐入模块，默认内容可见，关闭动画或依赖失效不隐藏内容。
2. 时间线在卡片刚进入视口时即消费纵向滚轮。改为先滚到整个时间线居中，再沿横轴推进；正反方向到边界均交回纵向余量。锚点进入时间线也居中。
3. 清理价值观、时间线的重复底部留白和整屏最小高度；手机项目示意区域不再占500px固定高度。
4. 工程页顶部间距未考虑已有正常流中的页眉；缩短首屏和服务区间距，修复手机标题单字换行，并压缩分类入口。
5. Windows 175% 缩放的分数像素取整可使阻尼动画永不收敛，进而覆盖锚点跳转。增加合理收敛阈值及 hash/popstate/预览定位中止机制。
6. 工作站模板 Project Alpha 没有真实入口。替换未改过的模板文案，新增可管理的项目作品链接；layoutVersion=6 迁移不覆盖作者自定义文案，也不复活迁移后删除的按钮。
7. 按钮文字字段原先不应用到工作站已有按钮，嵌套 span 按钮隐藏不完整。统一应用文案及完整链接的隐藏状态，清空覆盖可恢复原文。
8. 减少动画时技能条依赖旧动画、可能保持零宽；改为默认有正确宽度，仅入场时动画。背景粒子统一生命周期，后台/减少动态效果暂停，不依赖 GSAP。
