# 1.1 视觉语言与交互维护

目标：修正初版的小字、弱层级和重复卡片。让访客先看到个人定位与主标题，再看到作品规模、专业方向和具体案例。采用墨黑、银白与低饱和薄荷/蓝紫光色，不复刻其他品牌布局或标识。

## 内容层级

正文桌面目标 18–20px、手机 16px；关键标题按视口放大，保持字重和足够对比。辅助说明也须可读，不用极小字模拟高级感。标题由数据提供，多行由换行字符控制，英文与长名称必须自然折行，不能横向溢出。

首页职业定位放在主标题前，主标题第二行使用银白渐变。统计以主数字和有差别的层级组织，避免所有信息权重相同。每个精选项目保留技术、摘要、详情/GitHub 入口；不同项目场景使用独立图形，而不是重复窗口卡片。

## 文件责任

- `frontend/style.css`：可读的公开页样式、字体/间距/色彩、响应式与 motion 降级。后台样式独立，不再 import 公开页样式，避免视觉改版影响编辑器。
- `frontend/app.js`：DOM 和数据绑定。新标题/图形说明放 `copy.js`，后台可覆写，不写入用户运行数据。
- `frontend/field.js`：图形生命周期与六类 Canvas 概念场景；首页优先使用 `sculpture-gl.js` 的原生 WebGL 金属曲面，无 WebGL 或着色器失败时降级 Canvas。鼠标影响视角与反光，不使用外部 CDN。
- `frontend/motion.js`：原生滚动镜头参数、逐词亮起、局部光影/小角度视差与按钮轻微位移；事件统一清理，语言切换不累积监听器。

## 效果及边界

| 效果 | 驱动与范围 | 降级 |
| --- | --- | --- |
| 首页立体环形曲面 | WebGL / Canvas、鼠标、缓慢时间变化；下滑轻微改变透视 | 减少动画时静止；离屏/后台暂停；上下文丢失后替换画布并降级 Canvas |
| 首页镜头感 | 桌面 sticky 区域，原生 scroll 计算 `--camera-progress` | 手机短版、减少动画时不作长停留 |
| 宣言文字 | 按屏幕位置逐词提高亮度 | 基础文字始终存在；减少动画全亮 |
| 项目视觉 | 数据流、Agent 星图、语音波形、企业层叠结构、算法点云、业务连接六类 | 静止仍有完整图形，不影响阅读 |
| 局部光影 | pointermove 写入 `--spot-x/y` 与小角度 `--tilt-x/y` | 触屏与减少动画不启用 |
| 按钮响应 | 最大约 3px 的指针跟随、明确焦点状态 | 键盘/触屏保留标准按钮 |

这些图形全部属于概念表达，不能作为真实项目截图、数据图、模型训练曲线或产品能力证明。图形类型与项目 ID/已确认分类绑定，不能按项目排序来错误指派技术主题。

## 性能与可访问性

Canvas 使用 IntersectionObserver，仅可见图形绘制，约 30 帧每秒、像素比上限 1.7；没有后台永久计算。使用浏览器帧时间驱动速度，不把速度绑定到屏幕刷新率。参考 [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame) 与 [Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API)。

不监听并阻止 wheel/touchmove，不改变浏览器滚动惯性。保留 prefers-reduced-motion、键盘焦点、项目详情的 Escape/暂停视频/焦点返回。新增效果必须在减少动画设置动态变化时停止；关闭/切换语言应清理旧观察器与 RAF。

每次调整都检查 1440px、390px（包含英文）、文案长内容、后台导入样式、筛选首次点击、媒体和模态。尺寸与镜头参数不得依赖估算内容高度，否则跳到项目或筛选时会发生布局跳动。不得因为动效需要而重置 `local-data/`。
