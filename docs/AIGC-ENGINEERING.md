# AIGC工程页面与联系信息维护

## 路径与归属

公开页 `/?page=aigc`（生产前缀 /kuzpscv），源码属于 PSCV。页眉和首页引导均可进入。Home 页面管理 → 个人品宣 → AIGC工程，按 14 个板块维护；服务详情暂未制作，按钮禁用且标明筹备中。

## 管理内容

每项支持双语名称、宣传标题、痛点、解决思路、概念流程和业务栏目；流程与栏目用 | 分隔。概念图和业务图分别上传，未上传时使用 Canvas 技术示意与 DOM 业务界面示意。支持自动轮播开关、间隔、隐藏、删除、预览、保存和配置方案。服务按钮目前不接受跳转，避免误发布不存在的详情页。

联系区：邮箱、微信号、二维码全站共享；在 Home 的“联系我”板块编辑。联系方式由用户明确授权公开。二维码放在运行时媒体目录，不进入 Git；完整备份仍须包含媒体。清空微信号和二维码隐藏微信入口。隐藏单个页面联系板块不影响其他页面。

## 数据与运维

layoutVersion 5 一次性添加页面、首页引导和联系板块，保留用户已有联系配置。后续隐藏、删除不自动恢复。图片路径、邮件格式、轮播间隔均由后端验证；缺失媒体拒绝保存。revision 乐观锁、原子写入、备份与预设沿用现有机制。AIGC 作为独立页面纳入访问 PV 统计；不是独立访客统计。

业务图明确标注方案示意，不是客户交付截图，不编造部署、收益或准确率。所有实际服务范围需按需求确认。
